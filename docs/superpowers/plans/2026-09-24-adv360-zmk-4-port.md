### K1. Split transport commands (S3 defines; S1, S2 call through S3's helpers)

Appended to upstream's enum and union in `app/include/zmk/split/transport/types.h`. Appending keeps upstream's values stable. Indicators are **not** duplicated: upstream's existing `SET_HID_INDICATORS` command already delivers `zmk_hid_indicators_t` to peripherals and C1/C2 consume it there.

```c
enum zmk_split_transport_central_command_type {
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_POLL_EVENTS,
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_INVOKE_BEHAVIOR,
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_SET_PHYSICAL_LAYOUT,
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_SET_HID_INDICATORS,
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_SET_KINESIS_LED,       /* C3, new */
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_SET_KINESIS_BACKLIGHT, /* C3, new */
} __packed;

/* new union members inside struct zmk_split_transport_central_command.data */
struct {
    uint8_t layer;   /* highest active layer on central */
    uint8_t effect;  /* rgb underglow effect index */
    bool on;         /* underglow on/off */
} set_kinesis_led;

struct {
    uint8_t brightness; /* 0-100, already scaled */
    bool on;
} set_kinesis_backlight;
```

```c
/* app/include/zmk/split/central.h — S3 produces */
#if IS_ENABLED(CONFIG_ZMK_RGB_UNDERGLOW)
int zmk_split_central_update_kinesis_led(uint8_t layer, uint8_t effect, bool on);
#endif
#if IS_ENABLED(CONFIG_ZMK_BACKLIGHT)
int zmk_split_central_update_kinesis_backlight(uint8_t brightness, bool on);
#endif
/* Both: broadcast to every connected peripheral source; return 0 or -errno.
 * No-ops returning 0 when no peripheral is connected. */
```

### K3. BLE wire layout (S3)

Kinesis UUIDs; both are free on `main` (upstream uses 0x00–0x06).

```c
/* app/include/zmk/split/bluetooth/uuid.h */
#define ZMK_SPLIT_BT_CHAR_UPDATE_LED_UUID ZMK_BT_SPLIT_UUID(0x00000007)
#define ZMK_SPLIT_BT_CHAR_UPDATE_BL_UUID  ZMK_BT_SPLIT_UUID(0x00000008)
```

| Char | Offset | Size | Field |
|---|---|---|---|
| 0x07 LED | 0 | 1 | `layer` |
| 0x07 LED | 1 | 1 | `effect` |
| 0x07 LED | 2 | 1 | `on` (0/1) |
| 0x08 BL | 0 | 1 | `brightness` (0–100) |
| 0x08 BL | 1 | 1 | `on` (0/1) |

Write-without-response from central; peripheral validates length exactly (3 / 2 bytes) and returns `BT_ATT_ERR_INVALID_ATTRIBUTE_LEN` otherwise. The Kinesis pin's `indicators` byte is dropped from the wire (K1). Both halves are always flashed together, so no cross-version compatibility is required.

## Review Focus

1. **Right half stops mirroring lighting after sleep/reconnect:** on peripheral reconnect the central re-sends current LED and backlight state. Owning test: S3.
2. **Split drops/lockups under fast typing (A3):** LED/backlight sync never blocks key-position traffic; queue full drops the oldest sync, never a key event. Owning test: S3 (queue-full) and S5.
3. **User keymap fails to compile** with `&studio_unlock`, `&stp STP_BAT`, `&rgb_ug RGB_TOG`, `&bl BL_INC`: the config repo keymap builds in both variants. Owning check: S6, plus a copy of `config/adv360.keymap` built in S0's harness smoke test.
4. **Layer colors off by one / brightness scaling wrong:** parameterized test over all 32 layers and brightness 0/1/50/100 with `BRT_SCALE`. Owning test: S2.
5. **Keymap editor rejects the firmware:** layer names and behavior metadata match what Clique/editor expect (R3 decides). Owning test: S4.
