### K1. Split transport commands (S3 defines; S1, S2 call through S3's helpers)

Appended to upstream's enum and union in `app/include/zmk/split/transport/types.h`. Appending keeps upstream's values stable. Indicators are **not** duplicated: upstream's existing `SET_HID_INDICATORS` command already delivers `zmk_hid_indicators_t` to peripherals and C1/C2 consume it there.

```c
enum zmk_split_transport_central_command_type {
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_POLL_EVENTS,
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_INVOKE_BEHAVIOR,
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_SET_PHYSICAL_LAYOUT,
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_SET_HID_INDICATORS,
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_SET_KINESIS_LED,       /* C3, new */
    ZMK_SPLIT_TRANSPORT_CENTRAL_CMD_TYPE_SET_KINESIS_BACKLIGHT, /* C3, new */
} __packed;

/* new union members inside struct zmk_split_transport_central_command.data */
struct {
    uint8_t layer;   /* highest active layer on central */
    uint8_t effect;  /* rgb underglow effect index */
    bool on;         /* underglow on/off */
} set_kinesis_led;

struct {
    uint8_t brightness; /* 0-100, already scaled */
    bool on;
} set_kinesis_backlight;
```

```c
/* app/include/zmk/split/central.h — S3 produces */
#if IS_ENABLED(CONFIG_ZMK_RGB_UNDERGLOW)
int zmk_split_central_update_kinesis_led(uint8_t layer, uint8_t effect, bool on);
#endif
#if IS_ENABLED(CONFIG_ZMK_BACKLIGHT)
int zmk_split_central_update_kinesis_backlight(uint8_t brightness, bool on);
#endif
/* Both: broadcast to every connected peripheral source; return 0 or -errno.
 * No-ops returning 0 when no peripheral is connected. */
```

### K3. BLE wire layout (S3)

Kinesis UUIDs; both are free on `main` (upstream uses 0x00–0x06).

```c
/* app/include/zmk/split/bluetooth/uuid.h */
#define ZMK_SPLIT_BT_CHAR_UPDATE_LED_UUID ZMK_BT_SPLIT_UUID(0x00000007)
#define ZMK_SPLIT_BT_CHAR_UPDATE_BL_UUID  ZMK_BT_SPLIT_UUID(0x00000008)
```

| Char | Offset | Size | Field |
|---|---|---|---|
| 0x07 LED | 0 | 1 | `layer` |
| 0x07 LED | 1 | 1 | `effect` |
| 0x07 LED | 2 | 1 | `on` (0/1) |
| 0x08 BL | 0 | 1 | `brightness` (0–100) |
| 0x08 BL | 1 | 1 | `on` (0/1) |

Write-without-response from central; peripheral validates length exactly (3 / 2 bytes) and returns `BT_ATT_ERR_INVALID_ATTRIBUTE_LEN` otherwise. The Kinesis pin's `indicators` byte is dropped from the wire (K1). Both halves are always flashed together, so no cross-version compatibility is required.

### Contract additions and corrections (recorded by the critic, 2026-09-27)

Additions only; no K1–K6 item is renamed or re-typed. "Correction" marks a comment or node detail the prototypes proved wrong.

**K1**
- Guard: both helper prototypes sit under `#if IS_ENABLED(CONFIG_ZMK_SPLIT_KINESIS_SYNC)` (not `CONFIG_ZMK_RGB_UNDERGLOW` / `CONFIG_ZMK_BACKLIGHT`; identical on adv360, lets BSim enable sync on `nrf52_bsim`). Callers guard on `CONFIG_ZMK_SPLIT_ROLE_CENTRAL && CONFIG_ZMK_SPLIT_KINESIS_SYNC` (S3).
- Correction: `set_kinesis_backlight.brightness` is the **unscaled** `state.brightness` (0–100); each half applies its own `ZMK_BACKLIGHT_BRT_SCALE`. A scaled value double-scales the right half (S1 RF1, pinned by S1-T2 `update-vals`).
- Semantics: helpers never block, are callable before any connection, cache the last command, and `split/central.c` replays LED + backlight + the current HID indicators from `transport_status_changed_cb`; a cache whose `.type` is still 0 is never replayed (S3).

**K2**
- `zmk_rgb_underglow_set_periph()` ignores `periph.indicators` (S3 passes 0); both halves read lock LEDs from `zmk_hid_indicators_changed`. Returns `-EINVAL` for `layer >= 50` or `effect >= 7`. Also `ZMK_LED_NUMLOCK_BIT BIT(0)`, `ZMK_LED_CAPSLOCK_BIT BIT(1)`, `ZMK_LED_SCROLLLOCK_BIT BIT(2)` (S2).
- C3 hook: `static void zmk_rgb_underglow_central_send(void)` in `app/src/rgb_underglow.c`, called on layer/effect/on/off/init only, never from the 50 ms tick; its `LOG_DBG` line is pinned by S2's snapshots and stays (S2, filled by S3-T2).
- `zmk_backlight_update_vals()` clamps brightness to 100, applies the local scale once and schedules the debounced save; `zmk/backlight.h` includes `<stdbool.h>`/`<stdint.h>` (S1). `zmk_backlight_get_state()` is not needed: S3 sends from inside `zmk_backlight_update()`.

**K3**
- Wire payload = raw K1 union members (`BUILD_ASSERT` 3 and 2 bytes); the peripheral also rejects `offset != 0` (`BT_ATT_ERR_INVALID_OFFSET`) and normalises `on` with `!= 0`; chars are `BT_GATT_PERM_WRITE_ENCRYPT`, appended after `SELECT_PHYS_LAYOUT`; the central writes only when both handles are known and security ≥ L2 (S3).

**K4**
- S0 move: C7's `ZMK_KSCAN_DEBOUNCE_PRESS_MS/RELEASE_MS=15`, `ZMK_BEHAVIORS_QUEUE_SIZE=128`, `ZMK_SETTINGS_SAVE_DEBOUNCE=29500` are set in both `adv360pro_*_nrf52840_zmk_defconfig`; upstream defaults stay.
