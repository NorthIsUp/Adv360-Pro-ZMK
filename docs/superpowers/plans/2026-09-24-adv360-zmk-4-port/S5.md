`app/tests/ble/split/kinesis-sync-typing/kinesis_sync_typing_test.c`:

```c
/*
 * Copyright (c) 2026 The ZMK Contributors
 *
 * SPDX-License-Identifier: MIT
 */

// Every key event on the central also fires a lighting burst at the peripheral: more syncs than
// the queues hold, the load of layer-tap effect changes while typing. The host's reports are the
// snapshot, so a dropped, duplicated or reordered key shows there (Review Focus 2, A3).

#include <zephyr/kernel.h>

#include <zmk/event_manager.h>
#include <zmk/events/position_state_changed.h>
#include <zmk/split/central.h>

#if IS_ENABLED(CONFIG_ZMK_SPLIT_ROLE_CENTRAL)

static uint8_t layer;

// Simulated time only advances when a thread blocks, so elapsed time means a sync call stalled
// key processing. A failure halts the central, which cuts the host's reports short.
static int kinesis_sync_typing_listener(const zmk_event_t *eh) {
    int64_t start = k_uptime_get();

    for (int i = 0; i < 8; i++) {
        if (zmk_split_central_update_kinesis_led(layer++ % 32, 1, true) != 0) {
            k_panic();
        }
    }
    if (zmk_split_central_update_kinesis_backlight(layer % 100, true) != 0 ||
        k_uptime_get() != start) {
        k_panic();
    }
    return ZMK_EV_EVENT_BUBBLE;
}

ZMK_LISTENER(kinesis_sync_typing, kinesis_sync_typing_listener);
ZMK_SUBSCRIPTION(kinesis_sync_typing, zmk_position_state_changed);

#endif // IS_ENABLED(CONFIG_ZMK_SPLIT_ROLE_CENTRAL)
```

## Hardware BLE soak checklist (for the user, at final verification)

Simulation can't cover these, so they go to the user with the spec's one batched flash after C1–C9 land (spec, Testing 3, about 20 minutes together with the C1–C9 column). Flash both halves from the same build. Keep the rollback UF2s ready (`~/Downloads/adv360-8bd11ee/firmware-no-clique/*.uf2`). A failure means flashing those back, not debugging on the daily keyboard.

The key positions below refer to the user's `config/adv360.keymap` `mod` layer: `&bt BT_SEL 0`–`4` on the top row, `&bt BT_CLR`, `&rgb_ug RGB_TOG`, `&bl BL_INC` / `BL_DEC` / `BL_TOG`. The board build has `CONFIG_ZMK_SLEEP` off and `CONFIG_ZMK_IDLE_TIMEOUT=30000` with underglow and backlight auto-off on idle, so "sleep" here means the keyboard's 30 s idle and the host's own sleep. It does not mean ZMK deep sleep.

| ID | Check | Steps | Pass when |
|---|---|---|---|
| H1 | Re-pair each profile | For each profile 0–4 in use: `Mod + BT_SEL n`, then `Mod + BT_CLR`, then remove the keyboard in the host's Bluetooth settings and pair again | Each profile pairs on the first try, types from **both** halves within 5 s of pairing, and shows its profile colour (C1). The right half never needs a power cycle |
| H2 | Idle / host sleep → wake | (a) Leave the keyboard untouched for more than 30 s. Both halves' lights go off. Press a key on the left, then one on the right. (b) Put the host to sleep for 2 minutes or more, wake it, and type on both halves | (a) Both halves light up again with the same layer colour and backlight, and the first keypress on each half registers. (b) Both halves type within 5 s of the host waking, with no re-pair |
| H3 | Right half out of range and back | Switch to a non-default layer and change the backlight. Carry the right half about 10 m away, or into another room, until its keys stop registering on the host. Change the layer and backlight on the left, then bring the right half back | The right half's keys register again within 10 s. Within about 1 s of reconnecting it shows the left's **new** layer colour and backlight (S3 RF1: replay at ready). No power cycle |
| H4 | Host switch | Pair profile 0 and profile 1 to two different hosts. Type on both halves on host A, `Mod + BT_SEL 1`, type on both halves on host B, then switch back | Every switch reaches the target host within 5 s. Keys from both halves land only on the selected host. The profile colour follows the switch |
| H5 | Fast typing under lighting load (the hardware version of S5-T1) | Type fast for 2 minutes in a text editor while tapping layer keys and `&bl BL_INC`/`BL_DEC`, including 6+ keys at once | No dropped or stuck key, no lockup. The right half keeps mirroring lighting |
| H6 | Right half power-cycled while the lighting changes (from S3's Review Focus) | Switch the right half off. On the left, change the layer and the backlight. Switch the right half back on | Within about 1 s of reconnecting, the right half shows the new layer colour and backlight |
